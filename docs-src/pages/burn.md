Burning destroys tokens so they can't be used again. It reduces circulating supply.

## 📝 Steps

1. Open **Burn Token**.
2. Select the token and enter an amount (or use the max).
3. Review and confirm in your wallet.

## 💸 Fee

**0.02 SOL** plus the network fee.

## 💡 Good to know

- You can only burn tokens in **your own** wallet.
- Burning is **permanent**.
- Burning tokens is different from burning LP tokens. To lock liquidity, read [How to lock liquidity on Solana](/blog/lock-liquidity-on-solana-burn-and-earn/).
- For the full picture, see [What burning tokens means](/blog/what-burning-tokens-means/).
