DegenKit supports six networks with the same simple flow.

| Network | Token standard | Native coin | Good for |
|---|---|---|---|
| ◎ **Solana** | SPL | SOL | Fast, cheap launches and the biggest memecoin crowd |
| ⬡ **Ethereum** | ERC-20 | ETH | Maximum credibility and deep liquidity |
| 🟡 **BNB Chain** | BEP-20 | BNB | Low fees and a big retail audience |
| 🔵 **Base** | ERC-20 | ETH | Ethereum security with cheap transactions |
| 🟢 **Robinhood Chain** | ERC-20 | ETH | Building early on a new network |
| 🩵 **Elysium** | ERC-20 | HYPE | Very fast blocks in the Hyperliquid ecosystem |

## 🤔 How to choose

- **Where will your buyers be?** Launch where your community already trades.
- **What can you afford?** Ethereum gas can cost far more than Solana, BNB Chain, Base or Elysium.
- **Do you need a tax?** Tax tokens are available on EVM networks.
- **Do you want liquidity tools in one place?** Solana has Create and Remove Liquidity built in.

For a longer comparison, read [Which blockchain should you launch on?](/blog/which-blockchain-to-launch-token/).

## 🔄 Switching networks

Use the network selector at the top of the launcher, or open the network page directly: [Solana](/launch/solana/), [Ethereum](/launch/ethereum/), [BNB Chain](/launch/bnb/), [Base](/launch/base/), [Robinhood Chain](/launch/robinhood/), [Elysium](/launch/elysium/).

## 🩵 About Elysium

Elysium is Kinetiq's Layer 2 for the Hyperliquid ecosystem. It settles to HyperEVM and uses **HYPE** as its gas token, so you need HYPE on Elysium before you can create a token. HYPE reaches Elysium from HyperEVM through the official bridge; use only the bridge link published by Elysium's official channels. As far as we know the mainnet chain ID is **99901**, but always confirm network details from official sources before you add the network. Read the [Elysium explainer](/blog/what-is-elysium-kinetiq-hyperliquid-l2/) for more.
